# Batnab

Бичлэг үзэх, оруулах, хуваалцах YouTube маягийн видео сайт.

## Боломжууд

- **Бичлэг оруулах** — файлаа чирж оруулах эсвэл сонгох (MP4, WebM, MOV, MKV…, 500MB хүртэл), байршуулалтын явцыг харуулна
- Нүүр зургийг бичлэгээс автоматаар авна, эсвэл өөрийн зургийг оруулж болно
- Бичлэг тоглуулагч, үзэлтийн тоо, лайк / дислайк, хуваалцах холбоос
- Сэтгэгдэл бичих
- Хайлт (гарчиг, тайлбар, сувгийн нэрээр)
- Сувгийн хуудас — өөрийн оруулсан бичлэгийг устгах боломжтой
- Үзсэн түүх, таалагдсан бичлэгүүд
- Утас, таблет, компьютерт тохирсон

## Ажиллуулах

```bash
cd batnab
npm install
npm run dev          # http://localhost:3000
```

Production:

```bash
npm run build
npm start
```

## Тохиргоо (орчны хувьсагч)

| Хувьсагч | Анхны утга | Тайлбар |
| --- | --- | --- |
| `PORT` | `3000` | Серверийн порт |
| `MAX_VIDEO_MB` | `500` | Нэг бичлэгийн дээд хэмжээ (MB) |
| `BATNAB_DATA_DIR` | `./data` | Бичлэг болон мэдээллийн сан хадгалах хавтас |

Оруулсан бичлэгүүд `data/uploads/`, мэдээлэл нь `data/db.json` файлд хадгалагдана.

## Анхаарах зүйл

Нэвтрэх (бүртгэл) систем байхгүй. Сувгийн нэр, лайк, үзсэн түүх тухайн хөтөч (browser) дээр хадгалагдана.
Бичлэг оруулсан хүн тухайн хөтчөөсөө л устгах эрхтэй (сервер нууц түлхүүр өгдөг).
