# Batnab

Ангийн математикийн тестийн сайт. Бүртгэлийг багш үүсгэнэ, сурагч нэвтэрч тест өгнө, багш түлхүүр оруулж
дүн болон анализыг харна.

## Хэн юу хийх вэ

**Зочин (нэвтрээгүй)** — зөвхөн туршилтын тестийг (анхдагчаар Тест 1.А) өгч үзнэ. Дүн хадгалагдахгүй.

**Сурагч** — багшийн өгсөн нэвтрэх нэр, нууц үгээр нэвтэрнэ (өөрөө бүртгүүлэх боломжгүй).
- Тест өгөх бүрт бодлогуудын **байр холилдоно**; хуудсаа дахин ачаалахад дараалал, хариулт, цаг хадгалагдана.
- Дуусгахад хариулт нь хадгалагдаж, оноо болон аль бодлого дээр алдсан нь харагдана (түлхүүрийг багш оруулсан бол).
  Зөв хариултыг сурагчид харуулахгүй — зөвхөн багш харна. «Зөвхөн алдсанаа харах» товчоор алдсан бодлогуудаа шүүж харна.
- «Миний дүнгүүд»: тест бүрийн шилдэг дүн, бүх оролдлого, оролдлого бүрийн хариултыг номын дарааллаар харах.
- «Профайл»: хоч нэр, зураг солих, нууц үгээ солих.

**Багш (нэвтрэх нэр: Admin)** — «Багшийн самбар» (`/admin`):
- **Сурагчид**: нэг нэгээр эсвэл олноор (нэг мөрөнд нэг нэр) бүртгэл үүсгэх — нэвтрэх нэр, нууц үг автоматаар
  гарч, хуулах/CSV татах боломжтой. Сурагч бүрийн жинхэнэ нэр + хоч, оролдлогууд, нэр засах, түр хаах, устгах.
- **Түлхүүр**: цаасан хариултын хуудас шиг — бодлого бүрийн мөрөнд зөв үсгийг дарна (нүдэн тэмдэг дээр дарж бодлогыг
  харна), эсвэл «АБВГДБ…» / «1.В 2.В …» гэж нэг дор бичиж буулгана. Түлхүүрийг өөрчлөхөд бүх дүн шинээр тооцогдоно.
- **Анализ**: тест бүрийн дундаж ба өгсөн тоо, ангийн дүнгийн хүснэгт (сурагч × тест), сүүлийн оролдлогууд;
  тест бүрээр өгөөгүй сурагчид, онооны тархалт, хамгийн хүнд 5 бодлого, бодлого бүрийн зөв хувь болон аль хариултыг
  хэд сонгосон, сурагч бүрийн оноо.
- **Шалгалт**: тестийг тодорхой өдөр, эхлэх-дуусах цагтай шалгалт болгож товлоно. Эхлэхээс өмнө сурагчид тестийг нээж
  чадахгүй (тоолуур харагдана), шалгалтын үеэр нэг л удаа өгнө, хариулт нь явцдаа хадгалагдаж дуусах цагт өөрөө илгээгдэнэ.
  Шалгалт дуустал тэр тестийг дасгалаар өгөх, түлхүүрийг нь унших боломжгүй (дүрмээр, серверийн цагаар хянагдана).
  Багш хэн эхэлсэн, хэд хариулсан, хэдэн удаа хуудаснаас гарсныг шууд харж, дууссаны дараа дүн, анализ, CSV авна.
- **Тохиргоо**: туршилтын тест сонгох/унтраах, дахин өгөхийг зөвшөөрөх эсэх, бүх дүнг CSV-ээр татах.

**Хуудаснаас гарсныг тоолох**: тест эсвэл шалгалт өгөх үеэр сурагч өөр таб, апп руу шилжих (эсвэл өөр цонх руу 3 секундээс
удаан) бүрд тоологдож, гадуур байсан хугацааны хамт хадгалагдана. Сурагчид анхааруулга харагдана, багш дүн, шалгалтын
жагсаалтаас харна. Хуудсаа дахин ачаалах ч тоологдоно.

Хариултын түлхүүр кодонд байхгүй — зөвхөн мэдээллийн санд (`keys/<тест>`) багш оруулна.

**Долоо хоног бүр шинээр**: Баасан гараг бүрийн 24:00-д (Улаанбаатарын цагаар) бүх дүн цэвэрлэгдэнэ. Тэр мөчөөс
өмнөх дүн хаана ч харагдахгүй; сурагч сайтыг нээхэд өөрийнх нь, багш самбараа нээхэд бүх хуучин дүн мэдээллийн
сангаас устгагдана (дүрэм нь зөвхөн өмнөх долоо хоногийн дүнг устгахыг зөвшөөрнө). Бүртгэл, түлхүүр, тохиргоо хэвээр.
Багш цэвэрлэгдэхээс өмнө самбараас CSV татаж хадгалж болно.

### Шинэ тест нэмэх

1. `src/tests/test<дугаар><A|B>.tsx` файл үүсгэнэ (`test1A.tsx`-ийг дагана): бодлого бүр `q` (текст, томьёо
   `$…$` дотор — KaTeX), хэрэгтэй бол `fig` (зураг), `c` (5 сонголт А–Д).
2. Зураг: `src/components/figures.tsx`-ийн `Plot` (координатын хавтгай, шулуун, муруй, будсан муж) болон
   `Geo` (геометрийн зураг) — давтагддаг зургууд `src/tests/shared.tsx`-д.
3. `src/tests/index.ts`-д тестийн мэдээлэл болон ачаалагчийг нэмнэ. Түлхүүрийг багш самбараас оруулна.

## Автомат байршуулалт (GitHub Actions)

`.github/workflows/batnab-deploy.yml` нь `batnab/` өөрчлөгдөж push хийгдэх бүрт (`main` болон
`claude/youtube-site-batnab-jfgjry` branch) сайтыг build хийж Firebase руу байршуулаад `scripts/setup.mjs`-ийг
ажиллуулна. Энэ скрипт:
- Firebase Auth-ийн **Email/Password** нэвтрэлтийг асаана (нэвтрэх нэр `bold` → `bold@batnab.web.app` хаяг болж
  хадгалагдана; тэр хаяг руу юу ч илгээгддэггүй);
- багшийн **Admin** бүртгэлийг (байхгүй бол) үүсгэж, сайтын цорын ганц админ болгоно (хуучин Teacher001 байвал
  нууц үгийг нь хэвээр үлдээж Admin болгож нэрийг нь солино);
- анхдагч тохиргоог (туршилт = Тест 1.А, дахин өгөхийг зөвшөөрнө) бичнэ.

Repository secrets (GitHub → Settings → Secrets and variables → Actions):

| Нэр | Утга |
|---|---|
| `FIREBASE_SERVICE_ACCOUNT_RGTBN_BB94F` | Service account-ийн JSON түлхүүр (roles: **Firebase Admin**, **Service Usage Consumer**) |
| `BATNAB_ADMIN_PASSWORD` | Багшийн (Admin) анхны нууц үг (6+ тэмдэгт). Зөвхөн бүртгэл үүсгэхэд хэрэглэгдэнэ. |

Багш нууц үгээ сайтын «Профайл» хэсэгт сольж болно. Мартвал: secret-ийг шинэ нууц үгээр солиод GitHub →
Actions → **Deploy Batnab** → **Run workflow** → «reset_admin_password»-г чагтлан ажиллуулна.

Хэрэв лог дээр «Could not turn on Email/Password sign-in» гэж гарвал
[Firebase → Authentication → Sign-in method](https://console.firebase.google.com/project/rgtbn-bb94f/authentication/providers)
дээр **Email/Password**-ийг гараар асаана.

## Аюулгүй байдлын дүрмүүд (`database.rules.json`)

- `users/<uid>`: багш үүсгэж, засна; сурагч зөвхөн өөрийн `nickname`, `photo`-г солино.
- `results/<uid>/<тест>/<id>` = `{answers, seconds, at}`: идэвхтэй сурагч зөвхөн шинээр нэмнэ (засах боломжгүй;
  дахин өгөх хаалттай бол долоо хоногт нэг л удаа); өөрийн өмнөх долоо хоногийн дүнг л устгаж чадна. Оноог
  хадгалдаггүй — түлхүүрээр тооцно.
- `keys/<тест>`: зөвхөн багш бичнэ; сурагч тухайн тестийг өгсний дараа, зочин зөвхөн туршилтын тестийнхийг уншина.
- `exams/<тест>` = `{start, end}`: бүгд уншина, багш бичнэ. `examAnswers/<тест>/<uid>`: сурагч зөвхөн өөрийнхөө хариултыг
  шалгалтын хугацаанд (+1 мин) бичнэ, «дуусгасан» болсны дараа засах боломжгүй; гарсан тоо буурахгүй.
- `settings`: бүгд уншина, багш бичнэ. `admins`: хэн ч сайтаас бичиж чадахгүй.

## Хязгаарлалт

Сервер функцгүй (үнэгүй Spark төлөвлөгөө) тул багш сурагчийн нууц үгийг сольж чадахгүй. Сурагч нууц үгээ
мартвал шинэ нэвтрэх нэрээр дахин үүсгээд, хуучныг нь устгана.

## Ажиллуулах, турших

```bash
cd batnab
npm install
npm run dev          # http://localhost:3000

# Локал эмулятор дээр:
npx firebase-tools emulators:start --only auth,database
VITE_FIREBASE_EMULATORS=true npm run dev
FIREBASE_AUTH_EMULATOR_HOST=127.0.0.1:9099 FIREBASE_DATABASE_EMULATOR_HOST=127.0.0.1:9000 \
  ADMIN_PASSWORD=teach123 node scripts/setup.mjs   # Admin / teach123
```
