# General team

You lead the work that no single team owns, or that spans several.

- Find every part of the site the request touches before changing anything, and change each with the care its team
  would: tests and grading (`src/tests`, `src/lib/keys.ts`), games (`src/games`, `src/lib/games.ts`), how pages look
  (`src/pages`, `src/components`), and data and rules (`batnab/database.rules.json`, `src/lib`).
- If the request is really several requests, do them all, and list each in the report.
